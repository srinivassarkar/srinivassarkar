### Cloud DevOps & Platform Engineer | Hybrid Cloud & Edge AI Infrastructure

I’m a Platform Engineer with deep roots in backend microservices, specializing in high-reliability operations across AWS cloud environments and bare-metal Apple Silicon clusters.

Currently at **iProtechs**, I own operational uptime across 16+ microservices, engineer Zero-Trust ingress pipelines via Cloudflare Tunnels and Nginx, automate deployments with custom shell tooling, and serve as the primary on-call responder for Sev-1 production incidents.

---

### 🛠️ What I Do
* ☁️ **Hybrid Infrastructure:** Managing AWS cloud instances alongside dedicated on-prem Apple Silicon clusters (M3 Ultra & M4) running ONNX vision models and self-hosted vector databases.
* 🛡️ **Zero-Trust & Reliability:** Ingress routing via Cloudflare Tunnels (no open inbound ports), Nginx reverse proxying, and 99.9% uptime management.
* ⚡ **Systems & Daemon Engineering:** Linux `systemd` and macOS `launchd` process supervision, automated crash recovery, and memory-safe PM2 process trees.
* 🚨 **Incident Forensics & Triage:** Resolving live APFS storage starvation outages, containing host-level security compromises, and authoring post-mortem RCAs.
* 🔄 **GitOps & Cloud-Native:** Architecting multi-cluster Kubernetes platforms with EKS, ArgoCD ApplicationSets, Terraform IaC, and shift-left DevSecOps scanning.
